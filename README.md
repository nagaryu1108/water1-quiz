# water1-quiz

公害防止管理者 水質関係第1種の本試験型問題演習。

## 現在の分析方針

主分析対象を、平成18年度（2006年度）の新試験制度開始から令和7年度（2025年度）までの **現行制度20年分** に拡張しています。

- 5科目を年度横断で分析
- JEMAI/JEMAI CLUB公式資料を優先
- 法令・規制値・JIS・環境基準は2026年4月1日時点へ照合
- 環境省等の直近公表資料も「最新動向・予想」として反映
- 全5肢詳細解説
- 図・グラフ・表・計算・データ読解を含む
- 誤答履歴から弱点を優先再出題
- 新出用語は用語大辞典へ随時追加

監査の進行表は `analysis_scope_2006_2025.md` を参照してください。
