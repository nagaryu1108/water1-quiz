# water1-quiz

公害防止管理者 水質関係第1種の本試験型問題演習。

## 現在の分析方針

主分析対象を、平成18年度（2006年度）の新試験制度開始から令和7年度（2025年度）までの **現行制度20年分** に拡張しています。

- 5科目を年度横断で分析
- JEMAI/JEMAI CLUB公式資料を優先
- 法令・規制値・JIS・環境基準は最新の試験基準日へ照合
- 環境省等の直近公表資料も「最新動向・予想」として反映
- 全5肢詳細解説
- 図・グラフ・表・計算・データ読解を含む
- 誤答履歴から弱点を優先再出題
- 新出用語は用語大辞典へ随時追加

## v7 品質監査

- 36問 × 5肢 = **180肢**を詳細解説対象として監査
- 全肢で正誤理由を独立教材として扱う
- 誤答肢は、誤り箇所・理由・正しい文章・関連原理・典型的ひっかけを説明
- 正答肢も、理由・条件・関連知識・試験上の重要点まで説明
- 反応理解が重要な論点では代表反応式を付加
- 化学式は下付き、イオン電荷は上付き表示に変換して可読性を確保
- 専門用語は必要に応じミニ解説を付加
- 問題用図表と解答後補助グラフを区別し、解答前の答え漏れを防止
- 180肢の詳細解説、反応式、用語、図表についてランタイム品質監査を実施

## 解説の恒久仕様

- 割合・構成比・年度比較など、図示した方が理解しやすい統計は、問題を解くのに不要な場合に限り**解答後の補助グラフ**として表示する。
- 問題そのものがグラフ読解問題の場合、同じ内容の解説グラフを重複表示しない。
- 曲線A・B・Cなどの**凡例同定問題**も出題し、曲線形状＋専門知識から項目を判断させる。
- 処理・分析原理の理解に化学反応が重要な場合は、解説に代表反応式または反応の流れを簡潔に示す。
- 「○○法」「○○調査」「○○規制」などの専門用語は、問題理解に必要な短いミニ解説をその場に表示し、用語大辞典と整合させる。
- 最新統計は公表年度と測定年度を区別する。令和7年度国家試験は分析対象の最新版だが、公共用水域・地下水質測定結果は環境省が公表している最新測定年度を用いる。

監査の進行表は `analysis_scope_2006_2025.md` を参照してください。
